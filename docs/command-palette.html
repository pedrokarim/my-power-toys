🔍 Module Spotlight

Command Palette

Spotlight-like launcher for Linux. Search apps, run system commands, do quick calculations, search the web, and find files — all from a single floating search bar.

Activation shortcut: Alt + Space
Search Bar
Frameless, always-on-top floating bar. Start typing to search instantly.
Search Results
App icons, descriptions, and provider tags. Navigate with arrow keys, Enter to launch.

Features

⚡

Instant Search

Results appear as you type with fuzzy matching. Frecency-based ranking puts your most-used items first.

🖼

App Icons

Native PNG and SVG icon rendering from your system's icon themes. No placeholder icons.

🎨

Glassmorphism UI

Frameless floating window with dark glass design. Dynamically resizes as results appear. Auto-closes on focus loss.

⌨

Keyboard-First

↑ ↓ to navigate, Enter to launch, Esc to close. Never touch the mouse.

📊

Frecency Ranking

Learns from your usage. Frequently and recently used items bubble to the top automatically.

⚙

Configurable Providers

Enable or disable individual providers, change search engine, set max results, and more from the settings UI.
