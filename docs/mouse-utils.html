Mouse Utilities

Mouse Utilities — 6 cursor enhancements
Run in the background and activate on demand via configurable hotkeys.

Features

💡

Find My Mouse

Activate a spotlight that focuses on the cursor. Trigger by double-pressing Ctrl, shaking the mouse, or a custom shortcut. Configurable radius, colors, opacity and animation.

🔴

Mouse Highlighter

Display visual indicators when clicking. Separate colors for primary, secondary and always-on highlight. Choose between circle and spotlight modes.

✚

Mouse Pointer Crosshairs

Draw crosshairs centered on the cursor. Configurable color, thickness, opacity, orientation, border, and optional fixed length.

🚀

Mouse Jump

Move the mouse pointer long distances on a single screen or across multiple screens via a thumbnail popup.

🔄

Cursor Wrap

Seamlessly wrap the cursor around screen edges. Moving past one edge brings it back on the opposite side.

🎯

Gliding Cursor

Accessibility feature to control the mouse with a single button using guided horizontal and vertical lines.
