Light Switch

Automatically switch between light and dark mode based on time of day, sunrise/sunset, or toggle instantly with a keyboard shortcut.

Toggle shortcut: Super + Shift + D
☀️
Light Mode
06:00 — sunrise
⇄
🌙
Dark Mode
20:00 — sunset
Automatic theme switching based on your schedule or location.

Features

🌇

Sunset/Sunrise Scheduling

Automatically calculate sunrise and sunset based on your latitude and longitude. Dark mode activates at sunset.

🕘

Fixed Time Schedule

Set exact times for dark and light mode. For example, dark at 20:00 and light at 06:00.

⌨

Instant Toggle

Press Super+Shift+D to instantly switch between light and dark, overriding the schedule.

🎨

GNOME Integration

Uses gsettings to control color-scheme, GTK theme, and application preferences natively.

⚙

Granular Control

Choose to apply theme changes to the system UI, apps, or both. Fine-tune with sunrise/sunset offsets.

⚡

Lightweight Daemon

Runs as a background thread in the daemon. Checks every 60 seconds with minimal CPU usage. No separate binary needed.

Schedule Modes

🌇

Sunset to Sunrise

Uses the NOAA solar calculator to determine sunrise and sunset for your coordinates. Supports offsets to shift the switch earlier or later.

🕘

Fixed Hours

Set your own dark and light mode times in HH:MM format. Works anywhere without needing location data.

🔓

Manual Only

Disable automatic scheduling and use only the hotkey to toggle. Full control, no surprises.

Configuration

# ~/.config/my-power-toys/config.toml

[light-switch]
schedule_mode = "sunset-sunrise"   # "off" | "fixed" | "sunset-sunrise"
latitude      = 48.86                # Paris
longitude     = 2.35
sunrise_offset_min = 0          # shift sunrise earlier/later
sunset_offset_min  = -30        # switch 30 min before sunset

# Fixed schedule (when schedule_mode = "fixed")
dark_mode_time  = "20:00"
light_mode_time = "06:00"

# What to change
apply_system = true              # taskbar, system UI
apply_apps   = true              # supported applications
All settings are also available in the Settings UI under the Light Switch module page.
