Shortcut Guide

Never memorize a keyboard shortcut again. Trigger a translucent overlay that lists every shortcut on your system, grouped by category and rendered as clean keyboard badges.

Activation shortcut: Super + ?

Features

📑

Grouped by Category

Shortcuts are automatically grouped by category (System, Windows, Apps, Workspaces…) for quick scanning.

⌨

Keyboard Badges

Each key is rendered as its own badge, so Ctrl + Shift + A reads exactly like your keyboard.

🔧

Custom Shortcuts

Add your own shortcuts through the TOML config — app-specific bindings, personal muscle memory, team conventions.

🎨

Glassmorphism Overlay

Frameless, always-on-top, translucent panel. Auto-closes on focus loss or with Esc.

🛠

GNOME Shortcuts Preloaded

The most common GNOME/Linux shortcuts are bundled — disable them any time if you only want your custom set.

🔍

Hide Categories

Not interested in workspaces or app-launching shortcuts? Blacklist entire categories in the config.

Configuration

Configure Shortcut Guide via ~/.config/my-power-toys/modules/shortcut-guide.toml. All fields are optional.

# Show the built-in GNOME/Linux shortcut list (default: true)
show_gnome_shortcuts = true

# Hide entire categories (case-insensitive)
hidden_categories = ["Apps"]

# Add your own shortcuts
[[custom_shortcuts]]
keys = "Ctrl+Alt+T"
description = "Open terminal"
category = "Apps"

[[custom_shortcuts]]
keys = "Super+E"
description = "Open file manager"
category = "Apps"
