Awake

Keep your computer awake without changing power settings. Choose from four modes: indefinite, timed, expirable, or passive — with optional screen-on control.

♾ Indefinite
⏱ Timed
📅 Until Date
🔅 Screen On
Four operating modes inspired by Microsoft PowerToys Awake, adapted for Linux via D-Bus.

Features

♾

Indefinite Mode

Keep your system awake forever until you manually stop it. Perfect for long-running tasks, presentations, or downloads.

⏱

Timed Mode

Set a custom duration in hours and minutes. The system automatically returns to normal power behavior when the timer expires.

📅

Expirable Mode

Stay awake until a specific date and time. Ideal for overnight builds or scheduled tasks that must not be interrupted.

🔅

Screen Control

Independently toggle whether the display stays on. Prevent suspend while letting the screen dim, or keep both active.

💻

Tray Quick Access

Switch modes directly from the system tray submenu with radio buttons. No need to open the settings UI for quick changes.

⚡

Dual D-Bus Inhibition

Uses both org.freedesktop.ScreenSaver and systemd-logind for maximum compatibility. Graceful fallback if one fails.

Settings

🎵

Mode

Off, Indefinite, Timed, or Expirable. Saved to awake.toml.

🔅

Keep Screen On

Toggle display inhibition independently from suspend prevention.

⏱

Timer Duration

Hours and minutes for timed mode. Auto-stops when elapsed.

📅

Expiration Date

Target date/time for expirable mode (YYYY-MM-DD HH:MM).

💾

Persistent Config

Settings saved to ~/.config/my-power-toys/awake.toml.

🔌

Tray Submenu

Radio buttons for mode + screen toggle right from the tray icon.
