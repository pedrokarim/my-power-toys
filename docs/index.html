MyPowerToys

Suite d'utilitaires systeme pour Linux, inspiree de Microsoft PowerToys. Modulaire, legere et native.

Download GitHub
$ curl -fsSL https://raw.githubusercontent.com/pedrokarim/my-power-toys/main/packaging/install.sh | bash
Open Source Wayland + X11 Written in Rust Auto-Update

Built for Linux, from the ground up

Designed to be lightweight, modular, and deeply integrated with your desktop.

⚙

Modular

Each tool is an independent module. Enable only what you need, disable the rest.

⚡

Lightweight

Minimal daemon in memory. Modules are loaded on demand, not all at once.

🔨

Native

Built in Rust with native Wayland and X11 support. No Electron, no web views.

15+ Power Utilities

Everything you need to supercharge your Linux desktop.

Get Started

Install MyPowerToys on your Linux distribution.

Quick Install
curl -fsSL https://raw.githubusercontent.com/pedrokarim/my-power-toys/main/packaging/install.sh | bash
Arch Linux (AUR)
yay -S my-power-toys
From Source
git clone https://github.com/pedrokarim/my-power-toys && cd my-power-toys && cargo build --release
