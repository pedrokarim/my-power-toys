Hosts Editor

Visual editor for /etc/hosts — toggle entries on/off, add, edit and delete host mappings with a clean GUI. Saves with pkexec privilege elevation when needed.

Hotkey → mpt-hosts-editor
Hosts Editor Window
Browse, filter, toggle and edit /etc/hosts entries with inline editing and one-click save.

Features

🔒

Privilege Elevation

Saves via pkexec when direct write to /etc/hosts is denied. Automatic backup before each save.

🔘

Toggle Entries

Enable or disable host entries with a single click. Disabled entries are commented out and preserved.

🔍

Live Filter

Filter entries in real-time by IP address, hostname or comment. Instantly find what you need.

✎

Inline Edit & Add

Click any row to edit in-place. Add new entries at the top or bottom of the file.

💾

Auto Backup

Creates a timestamped backup in /tmp before every save, so you can always roll back.

📄

Preserves Structure

Comments, blank lines and inline comments are all preserved during roundtrip parse and save.
