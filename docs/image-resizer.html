🖼 Module Spotlight

Image Resizer

Batch resize images with built-in presets or custom dimensions. Drag and drop your files, pick a size, and resize them all at once.

Resize Window
Drop images, choose a preset, select output format, and resize in one click.

Features

📦

Batch Processing

Resize hundreds of images at once. Each file is processed in a background thread with a real-time progress bar.

📃

Drag & Drop

Drop images directly into the window or use the file picker dialog. Supports PNG, JPEG, WebP, BMP, GIF, and TIFF.

📏

Size Presets

Small (640px), Medium (1280px), Large (1920px), Phone (1080px), or enter a custom width.

🎨

Format Conversion

Convert to PNG, JPEG, or WebP while resizing. Keep the original format or switch to something smaller.

⚙

Quality Control

Adjust JPEG compression quality with a slider (1–100). Find the perfect balance between file size and image quality.

⚡

Lanczos3 Algorithm

Uses the Lanczos3 interpolation filter for sharp, high-quality downscaling with minimal artifacts.
