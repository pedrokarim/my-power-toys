Features

🔄

Key Remapping

Remap any key to another key, a shortcut combo, or disable it entirely. Classic use: CapsLock to Escape.

⌨

Shortcut Remapping

Remap shortcut combos to other shortcuts, single keys, or text. Supports modifier keys: Ctrl, Shift, Alt, Super.

💬

Text Snippets

Map any key or shortcut to send arbitrary unicode text. Type email signatures, code snippets, or emojis with a single press.

🚀

Launch Apps & URIs

Start applications or open URIs with a shortcut. Configure arguments, working directory, and elevation level.

🎯

Per-App Rules

Apply remappings only when a specific application is focused. Target apps by process name (e.g. firefox, code).

🎹

Chord Shortcuts

Create two-step shortcuts: hold modifiers + first key, then press a second key. Group related actions under one prefix.

How It Works

1

Open MyPowerToys Settings and navigate to the Key Manager module page.

2

In the Keys section, click Add key remap to remap single keys. In the Shortcuts section, add shortcut remaps.

3

Each mapping shows the trigger, action, and app filter. Use the toggle to enable/disable, or the × button to remove.

4

Changes are saved immediately to ~/.config/mpt/key-manager.toml and picked up by the daemon.
