Features

⌨

Keyboard Navigation

Use ← → to navigate between files in the same folder. Enter to open, Esc to close.

👁

File Manager Integration

Works with Nautilus, Dolphin, Thunar and more. Detects the selected file from your clipboard automatically.

🎨

Glassmorphism UI

Frameless, always-on-top floating window with a modern dark glass design. Auto-closes on focus loss.

📄

Rich Metadata

Shows file name, size, MIME type, image dimensions, and media duration at a glance.

🔄

Open with Default App

Press Enter or click "Open with" to launch the file in its default application via xdg-open.

⚡

CLI Support

Launch from the command line: mpt-peek /path/to/file. Works standalone or via the daemon.
