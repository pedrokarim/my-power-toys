📌 Module Spotlight

Always on Top

Pin any window to stay above all others with a single keyboard shortcut. A colored border and notification sound confirm the pin state instantly.

Activation shortcut: Super + T
A pinned window stays above all others, highlighted by a configurable blue border.

Features

📌

One-Key Toggle

Press Super + T to pin or unpin the focused window. No menus, no clicks.

🎨

Visual Border

A colored border appears around pinned windows so you always know which ones are on top. Configurable color, thickness and opacity.

🔈

Sound Notification

A short notification sound plays on pin and unpin, giving you instant audio feedback. Can be disabled in settings.

🚫

Excluded Apps

Configure a list of applications that should never be pinned. Uses WM_CLASS partial matching, case-insensitive.

🔄

Border Follows Window

Move or resize the pinned window and the border follows in real time with 100ms polling. No lag, no stale borders.

⚡

Lightweight

Zero-dependency overlay using raw X11 windows. No compositor plugins needed, works on any X11 window manager.

Settings

🎨

Border Color

HEX color for the border overlay. Default: #0078D4 (Windows blue).

📏

Border Thickness

1, 2, 3 or 5 pixels. Visible without being intrusive.

🔇

Border Opacity

0.0 to 1.0. Default 0.8 for a semi-transparent look.

🔈

Play Sound

Toggle notification sound on pin/unpin via canberra-gtk-play.

📌

Show Border

Toggle the visual border overlay entirely on or off.

🚫

Excluded Apps

List of WM_CLASS patterns to exclude from pinning.
