Features

🖥

Multi-Monitor

Detects all connected monitors. Each screen gets its own independent layout. Snap targets the monitor where the window is.

⌨

Keyboard & Mouse

Press 1-9 for instant zone selection. Use arrows to navigate, click to select, or Esc to cancel.

🎨

Visual Editor

Select monitors, pick templates, and preview zones in a graphical editor. Configuration saved per-monitor.

🛠

Per-Monitor Config

Assign different layouts to each monitor. Settings persist in your configuration file.

⚡

Transparent Overlay

Full-screen overlay with numbered zones, highlight on hover, and smooth visual feedback.

📋

Zone Gap

Configurable pixel gap between zones for clean visual separation between tiled windows.

How It Works

1

Press Super + Shift + Z to open the zone editor. Select your monitor and pick a template.

2

Focus the window you want to snap, then press Super + Z to bring up the zone overlay.

3

Click a zone, press its number 1-9, or use arrow keys + Enter to snap the window into place.
